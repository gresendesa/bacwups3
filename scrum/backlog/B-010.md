Montar o volume de origem como somente leitura e fixar a versão da imagem utilizada.

Exemplo:

```bash
-v "$target_name":/data:ro
```

* O contêiner não consegue alterar o volume de origem.
* A imagem Docker possui uma versão explícita.
* Falha no `docker run` interrompe o backup.
* A imagem utilizada é definida em um único local do código.
