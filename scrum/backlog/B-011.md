Adicionar um modo opcional para backup de projetos Git.

Na TUI:

```text
1. Diretório completo
2. Projeto Git, respeitando .gitignore
```

Utilizar o próprio Git para obter os arquivos:

```bash
git -C "$PROJECT_DIR" ls-files \
  --cached \
  --others \
  --exclude-standard \
  -z
```

Não implementar interpretação própria de `.gitignore`.

* `.gitignore` da raiz é respeitado.
* `.gitignore` em subdiretórios é respeitado recursivamente.
* Regras de negação com `!` são respeitadas.
* Arquivos rastreados são incluídos.
* Arquivos não rastreados e não ignorados são incluídos.
* Nomes com espaços e caracteres especiais funcionam.
* O diretório `.git` é excluído por padrão.
* O backup gerado continua completo e independente.
* Diretório que não seja repositório Git gera erro claro, sem fallback silencioso.
