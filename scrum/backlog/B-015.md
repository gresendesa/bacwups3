Permitir que o bacwups3 opere com um usuário IAM restrito a um único bucket S3, sem exigir `s3:ListAllMyBuckets`, e corrigir a validação de colisão remota para tratar objeto ausente como fluxo esperado.

## Acceptance Criteria

```yaml
section: backlog.item.B-015.acceptance-criteria
title: Acceptance Criteria
status: active
owner: "gresendesa"
created_at: 2026-07-13
updated_at: 2026-07-13

```

* A aplicação carrega `.env` sem imprimir segredos.
* Credenciais `ACCESS_KEY` e `SECRET_ACCESS_KEY` são mapeadas para as variáveis esperadas pela AWS CLI.
* Um bucket fixo configurado em `BACWUPS3_S3_BUCKET` evita chamada global a `aws s3 ls`.
* Usuário IAM sem `s3:ListAllMyBuckets` consegue operar no bucket permitido.
* A checagem de colisão usa `head-object` e aceita `404` como objeto ausente.
* Erros reais de permissão ou conectividade continuam interrompendo o backup.
* Existe teste automatizado local cobrindo a configuração IAM por `.env`.
* Existe teste real documentado contra bucket S3 de teste.

## Implementation Notes

```yaml
section: backlog.item.B-015.implementation-notes
title: Implementation Notes
status: active
owner: "gresendesa"
created_at: 2026-07-13
updated_at: 2026-07-13
tags: [implementation, backlog]
```

* Implementado `load_env_file` para carregar `.env` de forma limitada, sem executar o arquivo como script.
* A TUI chama `load_env_file "$DIR/.env"` antes de validar AWS.
* `check_aws_session_and_list_buckets` passa a validar apenas o bucket configurado quando `BACWUPS3_S3_BUCKET`, `S3_BUCKET` ou `AWS_S3_BUCKET` estiver definido.
* `.env` foi incluído no `.gitignore`.
* `ensure_s3_object_absent` passou de `aws s3 ls objeto` para `aws s3api head-object`, tratando `404`, `Not Found`, `NoSuchKey` e `NotFound` como ausência esperada.
* Adicionado `tests/env_iam_test.sh` ao runner local.
