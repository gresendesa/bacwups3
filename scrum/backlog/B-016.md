Corrigir o comportamento implementado em [@ref: B-011](B-011.md#backlog.item.B-011) e refletido em [@ref: B-012](B-012.md#backlog.item.B-012): no modo "Projeto Git, respeitando .gitignore", o diretório `.git` **não** deve ser ignorado.

Os arquivos ignorados por `.gitignore`, `.git/info/exclude` e excludes globais do Git devem continuar sendo ignorados para a árvore de trabalho. A mudança desejada é incluir os metadados do repositório Git no pacote para que o backup de projeto seja também um backup restaurável do repositório.

Exceção definida pelo PO durante a sprint: arquivos cujo nome comece com `.env` devem ser incluídos mesmo quando forem ignorados pelo Git.
