## Scope Boundaries

```yaml

title: Scope Boundaries
status: active
owner: "gresendesa"
created_at: 2026-07-13
updated_at: 2026-07-13
tags: [sprint, scope]
```

Incluído:

* Gerar manifesto com `jq` e validar campos obrigatórios no restore.
* Registrar `backup_mode: "full"` e campos mínimos do esquema inicial.
* Rejeitar hash vazio ou malformado e verificar retorno de `sha256sum`.
* Inspecionar `.tar.gz` antes da extração contra entradas absolutas, `..`, links perigosos e arquivos inválidos.
* Remover diretórios ou volumes criados pela operação quando a extração falhar.

Fora desta sprint:

* IDs únicos de backup e atomicidade remota pacote/manifesto.
* Endurecimento do backup de volumes Docker com imagem versionada.
* Backup de projeto Git e metadados Git além do que já existe.
* Suite completa ShellCheck/Bats.
